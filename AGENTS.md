# Agent instructions

This repo is a skill for building Garmin Connect IQ watch faces.

When the user asks for a Garmin watch face (new, changed, previewed or installed), read and
follow `skills/garmin-watchface/SKILL.md`. Its scripts are in `skills/garmin-watchface/scripts/`
and a starter face is in `skills/garmin-watchface/template/`.

`examples/prayer-watchface/` is a complete reference project (digital and analog faces, on-watch
settings, GPS location, Arabic text). Copy patterns from it rather than inventing new ones.
